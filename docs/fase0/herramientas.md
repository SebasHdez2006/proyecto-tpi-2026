# Fase 0 — Herramientas de desarrollo

| Herramienta | Elegida | Uso |
|---|---|---|
| Editor/IDE | VS Code | Desarrollo general |
| Control de versiones | Git | Repositorio del proyecto |
| Repositorio remoto | GitHub (internet) / Gitea autohospedado (intranet) | El mismo repo se empuja a uno u otro |
| Cliente de APIs | Bruno / Postman / curl | Pruebas de endpoints |
| Modelado UML | draw.io + PlantUML/Mermaid | Diagramas de análisis y diseño |
| Prototipo UI | Figma | Prototipo navegable (Etapa 3) |
| Gestor de dependencias | npm (frontend), pip + venv (backend) | Construcción |
| Contenedores | Docker + Docker Compose | Clúster reproducible |
| Pruebas de carga | k6 | Demostración del balanceo |
| Pruebas backend | pytest | Etapa 4 |
| Pruebas frontend | vitest | Etapa 4 |
